# 🎵 Music Streaming Listener Behavior Analytics Dashboard

![Dashboard Preview](music%20dashboard.jpg)

## Project Overview
An interactive Power BI dashboard designed to analyze user behavior and music consumption habits across major digital streaming platforms (e.g., Spotify, Apple Music, YouTube Music). This dashboard provides a comprehensive view of listener engagement—ranging from average listen time and skip rates to genre preferences and feature adoption across different subscription tiers and age demographics.

## Tech Stack & Tools
* **BI Tool:** Power BI Desktop
* **Data Modeling & Analytics:** DAX (Data Analysis Expressions)
* **Visualizations:** Treemap, Donut Chart, Stacked Bar Charts, KPI Cards, Custom Filters

## Key Responsibilities & Process
* Processed listener behavior dataset and crafted custom DAX measures to calculate key metrics, including *Total Listeners (4K)*, *Avg Listen Time (138.70)*, *Songs/Day (39.14)*, *Skip Rate (28.16)*, and *Premium User Ratio (29.83%)*.
* Engineered intuitive visual components including a Mood-based Skip Rate Treemap, Genre & Top Artist Leaderboards, Platform Market Share Distribution, and Engagement-Level Segmentation (*Light, Moderate, Heavy*).
* Implemented a multi-criteria filter panel allowing dynamic slicing by Country, Platform, Subscription Type (*Family, Premium, Free, Student*), Age Groups (*Teen to Senior*), alongside a dedicated *Reset Filters* button.

## Business Insights
* Enables precise mapping of listener habits across age brackets and subscription plans to inform user retention strategies.
* Provides actionable data regarding mood-based skip behaviors and genre/artist popularity to optimize playlist recommendation algorithms and content curation.
